# GitHub Training Workflow

Our normal workflow will eventually look like this:

main
  |
  +--> feature branch
          |
          +--> commits
          |
          +--> push
          |
          +--> Pull Request
                  |
                  +--> review
                  |
                  +--> requested changes
                  |
                  +--> approval
                  |
                  +--> merge
                          |
                          +--> main

We will intentionally break this workflow later to practice conflicts and recovery.
